# Отчёт 5: Механизм самообучения (Self-Improving) и фабрика навыков (Skills) в hermes-agent

Настоящий отчёт детально разбирает техническую реализацию механизма самообучения в проекте [nousresearch/hermes-agent](https://github.com/nousresearch/hermes-agent). В документе описано, как агент на лету создаёт, верифицирует, проверяет безопасность (AST-аудит), сохраняет и использует новые процедурные навыки (skills), а также приведены точные пути к файлам кода, промптов и справочников.

---

## 1. Архитектурная концепция: Процедурная vs Декларативная память

В `hermes-agent` разделены два типа долговременной памяти:
1. **Декларативная память (`MEMORY.md`, `USER.md`):** Факты, предпочтения пользователя, контекст окружения. Загружается в виде смысловых карточек.
2. **Процедурная память (`Skills`):** Алгоритмы решения задач («How-To»), скрипты, шаблоны и последовательности вызовов тулов. Хранятся в виде изолированных директорий с файлом спецификации `SKILL.md`.

Смысл механизма «Self-Improving» заключается в том, что когда агент сталкивается со сложной нетривиальной задачей или решает нестандартный кейс (либо пользователь даёт команду `/learn`), агент упаковывает полученный опыт в переиспользуемый навык. В последующих сессиях этот навык автоматически подтягивается в системный промпт и исполняется.

---

## 2. Жизненный цикл навыка «на лету» (End-to-End Pipeline)

Процесс эволюции агента состоит из пяти строго контролируемых фаз:

```
[Пользователь / Задача / /learn]
               │
               ▼
1. Синтез требований и структуры навыка (Prompting)
   (agent/learn_prompt.py + build_learn_prompt)
               │
               ▼
2. Вызов управляющего инструмента (Tool Invocation)
   (tools/skill_manager_tool.py -> skill_manage)
               │
               ▼
3. Валидация и статический линтинг (Linting & Hardline Rules)
   (tools/skill_linter.py -> _validate_frontmatter, lint_skill)
               │
               ▼
4. Аудит безопасности AST (Security AST Audit)
   (tools/skills_ast_audit.py -> _scan_source)
               │
               ▼
5. Атомарная фиксация и индексация в промпте (Atomic Write & Prompt Cache)
   (utils.py -> atomic_write_text; agent/prompt_builder.py -> build_skills_system_prompt)
```

## 3. Детальный разбор технических компонентов

### 3.1. Генератор промпта обучения: `agent/learn_prompt.py`
Функция `build_learn_prompt(target: str, ...)` компилирует специализированный промпт одного хода (single-turn prompt). Агент не использует сторонние «дистилляторы» — он применяет собственные встроенные инструменты (чтение файлов, поиск в сети, терминал) для извлечения сути и затем вызывает инструмент `skill_manage`.

В промпте зашиты жёсткие стандарты авторства (**HARDLINE rules**):
* **Frontmatter:**
  * `name`: lowercase-hyphenated, до 64 символов, без пробелов.
  * `description`: ровно **одно предложение не более 60 символов**, заканчивающееся точкой. Указывается только возможность («capability»), без маркетинговых слов («powerful», «advanced», «robust»). Ограничение в 60 символов критично: системный промпт усекает описание до 60 символов при загрузке индекса сессии!
  * `author`: всегда строго `Hermes` (запрещено брать имя текущего пользователя ОС для исключения утечек персональных данных).
  * `platforms`: явное объявление платформы (`[macos]`, `[linux]`, `[windows]`), если используются платформозависимые вызовы (osascript, apt, systemctl).
* **Структура директории:**
  ```
  ~/.hermes/skills/[category/]<skill-name>/
  ├── SKILL.md          (манифест + инструкция)
  ├── references/       (дополнительные справочники и документация)
  ├── scripts/          (вспомогательные bash/python скрипты)
  ├── templates/        (шаблоны файлов)
  └── assets/           (статические ресурсы)
  ```

### 3.2. Инструмент создания и редактирования: `tools/skill_manager_tool.py`
Управляет файловыми операциями навыков через функцию `skill_manage`:
* Поддерживает операции: `create`, `edit`, `patch`, `delete`.
* Обеспечивает межпроцессную безопасность через блокировки файлов `_skill_mutation_lock`.
* Производит валидацию размера контента (`_validate_content_size`), структуры YAML (`hermes_yaml`) и доступности категории.
* Запись файлов выполняется строго атомарно (`atomic_write_text`), что исключает повреждение базы навыков при сбоях или аварийном завершении процесса.

### 3.3. Структурный линтер: `tools/skill_linter.py`
Проверяет правила кодовой конвенции перед сохранением:
* Предотвращает неэффективные паттерны: запрещает в тексте инструкций рекомендовать сырые команды `cat`, `grep`, `head`, `sed`, направляя модель к использованию штатных инструментов `read_file`, `search_files`, `patch`.
* Проверяет длину описания (`SKILL_PROMPT_DESC_LIMIT = 60`).

### 3.4. Аудит безопасности AST: `tools/skills_ast_audit.py`
Если навык содержит исполняемые `.py` файлы (в каталогах `scripts/`), перед регистрацией запускается глубокий аудит абстрактного синтаксического дерева (AST):
* Анализируются вызовы `__import__`, `getattr`, `importlib`.
* Выявляются попытки динамического вычисления имен модулей, обхода песочницы или скрытой подгрузки вредоносного кода.

### 3.5. Прогрессивное раскрытие (Progressive Disclosure): `tools/skills_tool.py`
Чтобы не забивать контекстное окно LLM сотнями страниц документации навыков, используется двухуровневая модель:
1. **Первый уровень (`skills_list`):** Выдаёт только компактный список пар `(name, description)`.
2. **Второй уровень (`skill_view`):** Агент запрашивает полный текст конкретного навыка и связанные файлы из `references/` только тогда, когда задача действительно этого требует.

### 3.6. Встраивание в System Prompt и сохранение кеша промпта: `agent/prompt_builder.py` и `agent/system_prompt.py`
* Системный промпт `AIAgent` состоит из трёх уровней:
  1. `stable` (идентичность, правила форматирования, базовые инструкции).
  2. `context` (снимок рабочей директории, файлы контекста).
  3. `volatile` (индекс навыков, динамическая память, метка времени).
* **Сохранение Warm Prompt Cache:** Формирование индекса навыков (`build_skills_system_prompt`) вынесено в нижнюю, волатильную часть системного сообщения, либо кешируется в `_skills_prompt_snapshot_path`. Это гарантирует, что префиксный кеш токенов у провайдеров (OpenAI, Anthropic, DeepSeek) не сбрасывается при неизменном наборе активных навыков.
* Руководство модели по самообучению зашито в константу:
  ```python
  SKILLS_GUIDANCE = "When you work out a non-trivial workflow, record it with skill_manage for future reuse."
  ```

### 3.7. Граф обучения: `agent/learning_graph.py` и `agent/learning_mutations.py`
Для визуализации процесса эволюции агента (в TUI `/journey` и десктопном приложении):
* Модуль строит граф зависимостей между решёнными задачами, зафиксированными навыками и карточками долгосрочной памяти.
* Связи вычисляются на основе лексического пересечения и поля `related_skills`.
* Пользователь может просматривать историю развития агента, откатывать или редактировать созданные навыки (`learning_mutations.py`).

## 4. Точные пути к файлам кода, промптов и справочников

### Файлы промптов и правил:
1. **Основной промпт создания навыков:**
   - `/tmp/repos/hermes-agent/agent/learn_prompt.py` — функция `build_learn_prompt()`, содержит `_AUTHORING_STANDARDS` (жёсткие правила оформления, frontmatter, лимиты символов).
2. **Промпт-инструкции агента по использованию навыков:**
   - `/tmp/repos/hermes-agent/agent/prompt_builder.py` — константа `SKILLS_GUIDANCE`, функции `build_skills_system_prompt()`, `_render_skills_index()`.
3. **Сборка системного промпта:**
   - `/tmp/repos/hermes-agent/agent/system_prompt.py` — правила разделения слоев промпта (`stable`, `context`, `volatile`) для сохранения кеша.
4. **Специализированные системные навыки по созданию навыков (Skill-in-Skill):**
   - `/tmp/repos/hermes-agent/optional-skills/software-development/hermes-agent-skill-authoring/SKILL.md` — подробное руководство для агента по написанию новых навыков в соответствии со стандартами репозитория.

### Файлы исходного кода подсистемы Skills:
1. **Исполнение и просмотр навыков:**
   - `/tmp/repos/hermes-agent/tools/skills_tool.py` — инструмент `skill_view`, progressive disclosure.
   - `/tmp/repos/hermes-agent/tools/skills_tool_setup.py` — проверка переменных окружения и зависимостей навыка.
   - `/tmp/repos/hermes-agent/tools/skills_tool_plugin.py` — валидаторы инъекций и санитайзинг.
2. **Создание и мутация навыков:**
   - `/tmp/repos/hermes-agent/tools/skill_manager_tool.py` — инструмент `skill_manage` (атомарное создание, патчи, удаление).
   - `/tmp/repos/hermes-agent/tools/skill_lock.py` — файловые блокировки мутаций.
3. **Линтинг и аудит безопасности:**
   - `/tmp/repos/hermes-agent/tools/skill_linter.py` — синтаксический и стилистический контроль структуры навыка.
   - `/tmp/repos/hermes-agent/tools/skills_ast_audit.py` — глубокий статический AST-анализ Python-кода навыков.
4. **Граф эволюции и долгосрочная память:**
   - `/tmp/repos/hermes-agent/agent/learning_graph.py` — генерация графа знаний агента.
   - `/tmp/repos/hermes-agent/agent/learning_mutations.py` — управление изменениями в карточках памяти и навыков.
   - `/tmp/repos/hermes-agent/agent/skill_utils.py` — общие утилиты парсинга frontmatter и путей.

### Файлы документации и стандартов в репозитории:
