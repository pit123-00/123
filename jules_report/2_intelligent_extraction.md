# Интеллектуальное извлечение

## Техническая реализация и архитектура
Механизм проверки читаемости (Readability Engine) реализован с помощью библиотеки `trafilatura` (Python пакет для веб-скрейпинга и извлечения текста) и `BeautifulSoup`.
Также реализован специальный эндпоинт-прокси в `rsshub/blueprints/proxy.py` (`/proxy/readability`), который позволяет напрямую извлекать "чистый" текст из любого URL.
Внутри `/randomline` также используется "умное" падение (smart fallback) между `trafilatura` и сырым парсингом через `BeautifulSoup`.

## Функции и логическая работа
При обработке HTML-страниц и веб-статей (в `/randomline` или `/proxy/readability`):
1. **Trafilatura**: HTML-код сначала прогоняется через `trafilatura.extract(content, output_format='html')`. Эта библиотека использует эвристики для удаления рекламы, навигации, футеров и оставляет только основной контент статьи.
2. **Умный Fallback**: `randomline.py` проверяет результаты `trafilatura`.
   - Если это сайт Gutenberg (`gutenberg.org`), `trafilatura` пропускается, так как она может удалить нужные заголовки.
   - Сравнивается количество заголовков (`h1`-`h6`) в исходном HTML и в результате `trafilatura`. Если заголовки были удалены, алгоритм падает на сырой HTML.
3. **Семантическое извлечение (`_extract_semantic_text`)**: Очищенный HTML (от `trafilatura` или сырой) передается в эту функцию.
   - Она итерируется по тегам `['p', 'li', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6']`.
   - Поддерживает иерархию глав (запоминает последний встреченный заголовок `h1`-`h6`, чтобы привязать абзац `p` к нужной главе).
   - Если параграф содержит переносы строк `<br>`, они корректно разбиваются, если включена опция `split_lines`.
4. В эндпоинте `/proxy/readability` просто вызывается `trafilatura.extract(response.text)` и возвращается чистый текст как `text/plain`.

## Обмен информацией, память и потоки данных
- На входе: Грязный HTML с рекламой, меню и скриптами.
- На выходе: Очищенный текст или JSON структура (через семантический разбор: `[{"chapter": "Chapter 1", "line_content": "Text here"}, ...]`).
- `trafilatura` может также извлекать метаданные (например, заголовок статьи `metadata.title`), которые используются для названия RSS-ленты.
