# Интеграция с Anki

## Техническая реализация и архитектура
Интеграция с Anki построена вокруг плагина **AnkiConnect**, который запускает локальный HTTP-сервер (по умолчанию на порту 8765) для взаимодействия с запущенным десктопным приложением Anki.
Модуль для RSSHub реализован в `rsshub/spiders/anki/due_cards.py`.
Архитектурно это адаптер (spider), который делает REST API запросы к AnkiConnect и преобразует полученные JSON данные карточек в формат RSS ленты.

## Функции и логическая работа
При генерации RSS ленты для Anki:
1. **Проверка соединения**: Сначала отправляется POST запрос `{"action": "version"}` на `http://localhost:8765` (или URL из переменных окружения).
2. **Поиск карточек (findCards)**: Вызывается `{"action": "findCards", "params": {"query": "is:due"}}`, чтобы получить ID всех карточек, которые ожидают повторения (due) сегодня.
3. **Получение информации (cardsInfo)**: По полученным ID запрашивается детальная информация о карточках (включая имя колоды `deckName`).
4. **Случайный выбор карточки**:
   - Карточки группируются по колодам (`cards_by_deck`).
   - Случайным образом выбирается одна колода, а из нее — случайная карточка (это обеспечивает равномерное распределение, если в одной колоде 1000 карточек, а в другой 5).
5. **Получение содержимого (notesInfo)**: Для выбранной карточки запрашивается информация о самой заметке (note).
6. **Извлечение полей**: Парсер пытается найти поля Вопрос (`Front` или `Question`) и Ответ (`Back` или `Answer`). Если они не найдены, берутся первые два поля.
7. **Формирование RSS**:
   - Заголовок: Вопрос (до 100 символов).
   - Описание (Description): Подробный HTML с ответом, информацией о карточке (Deck, Card Type, Queue, Model), статистикой повторений (всего повторений, ошибки, интервал в днях, Ease Factor) и тегами.

## Обмен информацией, память и потоки данных
- **Внешняя зависимость**: Для работы требуется запущенное локальное (или доступное по сети) приложение Anki с установленным дополнением AnkiConnect (код 2055492159).
- **Поток**: `RSSHub -> (HTTP POST, JSON) -> AnkiConnect -> Anki Database (sqlite)`. И обратно JSON массив с карточками.
- Конфигурация хоста и порта задается через параметры URL или переменные окружения `ANKI_CONNECT_HOST` и `ANKI_CONNECT_PORT`.
- Результатом является RSS лента с одной выбранной карточкой. Так как этот endpoint вызывается RSS-клиентом периодически, пользователь будет получать новую карточку для повторения в своей ленте через промежутки времени.
