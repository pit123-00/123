# Поддержка различных источников

## Техническая реализация и архитектура
Проект использует Python с фреймворком Flask. Поддержка различных источников реализована в `rsshub/spiders/randomline/randomline.py`.
Поддерживаются различные форматы: CSV, TSV, TXT, PDF, EPUB, MOBI, JSON и HTML.
Архитектурно это реализовано через единый endpoint `/randomline`, который принимает URL файла и другие параметры, скачивает файл и затем обрабатывает его в зависимости от расширения или содержимого.

Для поддержки специфичных форматов (PDF, EPUB, MOBI) используются сторонние библиотеки:
- `ebooklib` для EPUB
- `mobi` для MOBI
- `fitz` (PyMuPDF) для PDF

## Функции и логическая работа
При запросе к `/randomline`:
1. Скачивается содержимое по указанному URL с помощью `requests`.
2. В зависимости от расширения файла или заголовка Content-Type:
   - **PDF:** Извлекается текст с помощью `fitz`, параграфы могут объединяться, если строка не заканчивается точкой.
   - **EPUB:** Извлекаются HTML-главы (`ITEM_DOCUMENT`) через `ebooklib`, затем парсятся `BeautifulSoup`.
   - **MOBI:** Извлекается HTML содержимое через `mobi`, затем парсится.
   - **CSV/TSV/TXT:** Текст разбивается по разделителю (заданному пользователем или автоопределенному `\n`). Поддерживается извлечение конкретной колонки (`title_col`).
   - **HTML (web):** Используется извлечение текста через библиотеку `trafilatura` или парсинг `BeautifulSoup` (об этом подробнее в пункте "Интеллектуальное извлечение").
3. Содержимое нормализуется в список блоков (строк или абзацев).
4. Происходит фильтрация по длине `min_length`.
5. Случайно выбирается один из блоков `random.choice(indexed_rows)`.
6. Генерируется RSS-item с этим текстом, возможно добавление контекста (предыдущей и следующей строк), а также ссылок на ChatGPT, Google, Xiaohongshu, Felo для 해석 (интерпретации) этого текста.

## Обмен информацией, память и потоки данных
Данные поступают через HTTP-запрос (URL). Скачиваются во временный файл (`tempfile.NamedTemporaryFile`) для EPUB/MOBI/PDF или в память для текста.
После парсинга формируется словарь, представляющий собой RSS канал:
```python
{
    'title': feed_title,
    'link': url,
    'description': 'Random item from ...',
    'items': [{'title': ..., 'description': ..., 'link': ...}]
}
```
Этот словарь затем преобразуется во фреймворке в XML (RSS/Atom). Кэширование запросов реализовано через декоратор `@cache.cached()`.
