# Отчет по fivefilters-full-text-rss-docker

## 1. Техническая реализация и архитектура
Проект представляет собой контейнеризированную (Docker) версию инструмента Full-Text RSS (от fivefilters.org) на базе PHP-Apache (с использованием legacy версии PHP 5).
Его главная архитектурная особенность — это многостадийная сборка (multi-stage build) в `Dockerfile`:
1. Скачивание исходного кода движка Full-Text RSS.
2. Скачивание базы конфигураций сайтов (`site_config`) из отдельного репозитория (`fivefilters/ftr-site-config`).
3. Сборка финального образа с установленным расширением `tidy` для очистки и парсинга HTML, и копирование конфигураций.
Запуск сервиса происходит через `docker-compose.yml`, где сервис поднимается как API-узел (порт 80 по умолчанию) с подключением volume для кеширования RSS-лент.

## 2. Функции и логическая работа
- **Использование базы site_config (XPath/CSS правила) для очистки:**
  База `site_config` состоит из текстовых файлов (для разных доменов), содержащих XPath и CSS селекторы. Эти правила указывают движку, какие элементы HTML-страницы содержат основной контент статьи (`body`), какие элементы нужно удалить (реклама, навигация, комментарии - `strip`), и как извлекать авторов, даты и метаданные. Файлы конфигурации копируются в директорию `/var/www/html/site_config/standard/` внутри контейнера. Движок автоматически применяет нужный конфиг, когда URL запроса совпадает с именем домена.
- **Запуск сервиса как API-узла для NormalizerLayer:**
  Сервис имеет два основных HTTP эндпоинта (описаны в Readme):
  - `extract.php?url=[url]` - принимает URL статьи и возвращает извлеченный очищенный полный текст (Full Text). В контексте Ingestion pipeline это может использоваться в NormalizerLayer, где система отправляет "грязную" ссылку на статью и получает обратно структурированный и очищенный контент, пригодный для дальнейшей обработки (LLM, Embeddings).
  - `makefulltextfeed.php?url=[url]` - принимает ссылку на неполный RSS/Atom feed, обходит ссылки внутри него и генерирует новый feed с полным текстом.

## 3. Обмен информацией, память и потоки данных
- Клиент делает HTTP GET запрос на `extract.php` или `makefulltextfeed.php` с целевым URL.
- Если данные уже были извлечены ранее, они отдаются из файлового кеша (`/var/www/html/cache/rss`), который монтируется как Docker Volume для персистентности.
- Если данных в кеше нет, PHP-скрипт скачивает HTML по указанному URL.
- Загруженный HTML очищается через библиотеку `tidy`.
- Ищется соответствующий файл конфигурации в папке `site_config`. На основе XPath/CSS-правил из этого файла извлекается смысловой контент (Full Text).
- Сформированный (нормализованный) результат конвертируется в запрошенный формат (JSON, XML/RSS) и возвращается клиенту по HTTP, а также сохраняется в кеш.
