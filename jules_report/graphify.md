# Отчет: graphify
Multimodal knowledge graph for codebases and technical corpus.

## 1. Назначение проекта
Graphify — это мощный инструмент для извлечения знаний, который стирает грань между кодом, документацией и мультимедиа-контентом. Его цель — построить «цифровой двойник» знаний проекта. В отличие от стандартных индексаторов, Graphify умеет связывать строчку в Python-файле с обоснованием, высказанным архитектором на видеозаписи митинга или нарисованным на фотографии маркерной доски.

## 2. Архитектура и технический стек
Проект представляет собой сложную многоуровневую систему на Python:
- **AST Pass (Tree-sitter):** Детерминированное извлечение структуры кода для 23 языков. Работает локально и очень быстро.
- **Media Pass (faster-whisper + yt-dlp):** Локальная транскрибация аудио и видео. Звук никогда не покидает машину пользователя. Используются промпты, адаптированные под домен проекта (Domain-aware prompting).
- **LLM Pass (Claude Vision/Text):** Семантический слой. LLM используется только там, где нужен интеллект — для связи концептов, анализа изображений и извлечения «дизайн-рацио» (обоснований).
- **Graph Engine (NetworkX + Leiden):** Использование графовых алгоритмов для кластеризации и анализа топологии знаний.

## 3. Логика работы и функции
### Процесс «Графификации»:
1. **Сбор корпуса:** Вы просто бросаете в папку `/raw` всё, что есть по проекту: код, PDF, скриншоты, записи Zoom.
2. **Многомодальная экстракция:**
    - Код парсится в узлы `Function`, `Class`.
    - Из комментариев `# NOTE:`, `# WHY:` извлекаются узлы `rationale`.
    - Из PDF добываются цитаты и концепты.
    - Из видео создаются транскрипты, которые затем анализируются как текст.
3. **Топологическая кластеризация:** Алгоритм Leiden находит группы узлов с высокой плотностью связей. Эти группы становятся «сообществами» в графе знаний.
4. **Генерация отчетов:** Создается `GRAPH_REPORT.md`, интерактивный HTML-граф и база данных JSON.

### Ключевые аналитические функции:
- **God Nodes Detection:** Выявление «центральных» концептов системы, через которые проходит большинство связей.
- **Surprising Connections:** Алгоритм ищет связи с высоким весом между узлами, которые находятся в разных файлах или даже разных модальностях (например, связь кода и параграфа в PDF-статье).
- **Design Rationale Extraction:** Автоматический сбор обоснований. Система отвечает не только на вопрос «что делает код», но и «почему он сделан именно так».
- **Confidence Scoring:** Каждое ребро в графе имеет статус: `EXTRACTED` (факт из кода), `INFERRED` (логический вывод ИИ с оценкой уверенности 0.0-1.0) или `AMBIGUOUS` (требует проверки человеком).

## 4. Нестандартные решения
- **Clustering without Embeddings:** Это смелое решение. Вместо того чтобы полагаться на векторную близость (которая часто ошибается в нюансах), Graphify использует топологию графа. Сходство определяется тем, насколько часто концепты упоминаются рядом или связаны структурно. Это дает гораздо более точную группировку по смыслу.
- **Hypergraph Support:** Возможность создавать связи, объединяющие 3 и более узлов. Это необходимо для описания сложных архитектурных паттернов или потоков данных.
- **Domain-aware Transcription:** При транскрибации видео система сначала читает код проекта, извлекает специфические термины и скармливает их Whisper как подсказки. Это радикально повышает точность распознавания технических терминов.
- **Obsidian Integration:** Опциональная генерация хранилища (vault) для Obsidian, что превращает граф проекта в удобную персональную базу знаний с обратными ссылками.

## 5. Вывод
Graphify — это «сверхмощный микроскоп» для анализа технического контекста. Его нестандартность заключается в отказе от узкого фокуса на коде в пользу широкого мультимодального охвата. Это идеальный инструмент для тех, кто наследует огромные легаси-проекты с плохой документацией, но большим архивом смежных материалов.
