# 1. Техническая реализация и архитектура
В скрипте `genRSS` (в модуле `generss/util.py`) реализована гибридная стратегия извлечения метаданных из локальных медиа-вложений для генерации RSS-фида. Архитектура полагается на последовательный откат (fallback) по библиотекам: сначала используется легковесная библиотека на Python `mutagen` (или `eyed3` для mp3), и если они не справляются, скрипт вызывает внешние CLI утилиты (такие как `sox` и `ffprobe`). Это позволяет сбалансировать скорость работы (чтение тегов в Python быстрее) и надежность (ffprobe поддерживает больше форматов).

# 2. Функции и логическая работа
Ключевая функция `get_duration_mutagen(filename)` пытается открыть файл с помощью классов библиотеки `mutagen` (`mutagen.mp3`, `mutagen.mp4`, или универсального `mutagen.File()`).
Логика:
- Выполняется блок `try-except` для перехвата `ImportError` (если mutagen не установлен) и специфичных ошибок парсинга (например, `HeaderNotFoundError`).
- Объект `mutagen.File` возвращает словарь-подобный объект, содержащий метаданные файла (ID3-теги, информацию о потоке).
- Считывается свойство `info.length`, которое возвращает длительность аудио/видео трека в секундах.
- Аналогичная логика применяется в функции `get_title()`: если передан флаг использования метаданных, скрипт извлекает тег `title` через `EasyID3` или `EasyMP4` перед тем, как откатиться к использованию имени файла.

# 3. Информационный обмен, память и потоки данных
Взаимодействие происходит исключительно с локальной файловой системой.
- При сканировании директории путь к медиа-файлу передается в функцию извлечения метаданных.
- `mutagen` читает только заголовки файла (header/ID3-теги), не загружая весь медиафайл в оперативную память. Это критически важно для производительности при обработке больших видео или Lossless аудио файлов.
- Извлеченные значения (название, длительность) нормализуются (округляются до целых секунд для длительности) и возвращаются как скалярные типы (string, int), после чего встраиваются в XML структуру RSS-фида в виде тегов `<itunes:duration>` и `<title>`.
