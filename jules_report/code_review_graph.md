# Отчет: code-review-graph
Stop burning tokens. Start reviewing smarter.

## 1. Назначение проекта
`code-review-graph` — это инновационный плагин для Claude Code, решающий проблему «токенного голода» и контекстной перегрузки при работе ИИ-ассистентов с большими кодовыми базами. Основная концепция заключается в переходе от чтения «всего подряд» к чтению только того, что действительно затронуто изменениями. Проект строит структурную карту репозитория, отслеживает связи между сущностями и предоставляет ИИ-ассистенту минимально необходимый, но при этом максимально полный контекст для качественного код-ревью.

## 2. Архитектура и технический стек
Проект реализован на Python и демонстрирует высокоуровневую инженерную культуру. Ключевые архитектурные блоки:
- **Многоязычный парсер на Tree-sitter:** В отличие от простых регулярных выражений, проект использует полноценные грамматики Tree-sitter для 19+ языков (включая Perl XS и Jupyter Notebooks). Это позволяет извлекать не только имена функций, но и call-graph (граф вызовов) с высокой точностью.
- **Графовое хранилище на SQLite:** Выбор SQLite оправдан локальностью инструмента. База данных хранит узлы (`nodes`) и связи (`edges`). Схема оптимизирована индексами по квалифицированным именам (`qualified_name`) и путям файлов.
- **NetworkX для анализа:** Для тяжелых вычислений на графе, таких как поиск кратчайших путей или расчет радиуса поражения, используется библиотека NetworkX.
- **Интеграция через MCP:** Проект полностью поддерживает Model Context Protocol. Это позволяет Claude Code вызывать инструменты анализа графа напрямую через унифицированный интерфейс.

## 3. Логика работы и функции
### Процесс построения и обновления:
1. **Индексация:** Проект сканирует файлы, отсеивая лишнее (бинарные файлы, node_modules) через `.code-review-graphignore`.
2. **Экстракция сущностей:** Для каждого файла строится AST. Извлекаются классы, функции, импорты. Генерируются квалифицированные имена вида `path/to/file.py::ClassName.method_name`.
3. **Генерация связей:** Основные типы ребер — `CALLS` (вызовы), `IMPORTS_FROM` (зависимости), `INHERITS` (наследование), `TESTED_BY` (связь кода с тестами).
4. **Инкрементальность:** Это «сердце» проекта. При изменении кода инструмент выполняет `git diff`, находит измененные файлы и только их (а также их зависимости) перепарсивает. Обновление графа на проекте из 3000 файлов занимает менее 2 секунд.

### Ключевые аналитические функции:
- **Blast-radius Analysis:** При получении диффа, алгоритм BFS проходит по графу от измененных узлов. Он находит не только то, что изменилось, но и всех «клиентов» этого кода, которые могут сломаться.
- **Flow Detection:** Автоматическое обнаружение потоков исполнения (Execution Flows) от точек входа до целевых функций. Это помогает ИИ понять бизнес-логику процесса, а не просто видеть изолированный кусок кода.
- **Community Detection (Алгоритм Leiden):** Автоматическая кластеризация кода на «сообщества». Это помогает выявить скрытую модульность проекта и подсветить слишком тесно связанные компоненты (High Coupling).
- **Semantic Search:** Гибридный поиск, сочетающий FTS5 (полнотекстовый поиск в SQLite) и векторные эмбеддинги. Это позволяет найти код по смыслу: например, запрос «аутентификация» найдет соответствующие функции, даже если в их названии нет этого слова.

## 4. Нестандартные решения и инновации
- **Structural Review Guidance:** Проект генерирует для ИИ не просто код, а «руководство к действию». Он подсвечивает: «Этот метод изменен, он вызывается в 15 местах, но покрыт тестами только в 2. Обрати на это внимание».
- **Notebook Support:** Редкая функция — полноценный разбор Jupyter и Databricks ноутбуков с поддержкой многоязычных ячеек (Python, R, SQL) внутри одного файла.
- **Multi-repo Registry:** Возможность зарегистрировать несколько зависимых репозиториев и выполнять кросс-репозиторный поиск.
- **Wiki Generation:** Автоматическая генерация Markdown-вики на основе структуры сообществ. Это превращает код в живую документацию без усилий со стороны человека.

## 5. Вывод
`code-review-graph` — это проект, задающий стандарт для инструментов ИИ-разработки следующего поколения. Его нестандартность заключается в глубоком понимании структуры кода и умении превратить «плоский» текст репозитория в многомерный граф знаний, оптимизированный для потребления нейросетями.
