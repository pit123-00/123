# 1. Техническая реализация и архитектура
`EntryFilter` — это класс данных (NamedTuple в `reader/_types.py`), который инкапсулирует критерии для фильтрации записей. Он используется на уровне ядра и хранилища (в частности, в `reader/_storage/_entries.py`) для динамического построения SQL-запросов. Архитектурно `EntryFilter` выступает как объект передачи данных (DTO), который абстрагирует веб-слой или пользовательский интерфейс от конкретных SQL-конструкций. Пагинация реализуется через методы `get_entries()`, которые принимают объекты фильтра, лимиты (`limit`) и курсоры (`starting_after`).

# 2. Функции и логическая работа
`EntryFilter` предоставляет стандартизированный набор параметров: `feed` (конкретный фид), `read` (статус прочтения), `important` (важность), `has_enclosures` (наличие медиафайлов) и теги (`tags`, `feed_tags`).
Когда ядро вызывает метод получения записей, оно передает `EntryFilter` в класс хранилища. Логика хранилища:
- Разбирает атрибуты фильтра.
- Динамически добавляет секции `WHERE` в базовый SQL запрос.
- Для пагинации применяется метод на основе курсора (keyset pagination): используется аргумент `starting_after`, содержащий кортеж значений (например, дата публикации и ID), что обеспечивает быструю навигацию по `O(1)` в сравнении с традиционным `OFFSET`.
- Применяется лимит записей `LIMIT`.

# 3. Информационный обмен, память и потоки данных
Поток данных начинается с пользовательского запроса (например, через веб-дашборд или API), где параметры превращаются в экземпляр `EntryFilter`.
Затем `EntryFilter` и параметры сортировки/пагинации передаются в хранилище. Хранилище транслирует эти абстрактные фильтры в конкретный SQL (с использованием плейсхолдеров для безопасности) и отправляет запрос в SQLite.
База данных возвращает ограниченный (лимитом) набор строк. Эти строки проецируются на объекты доменной модели `Entry`. Память экономится за счет того, что загружается только одна страница записей за раз, а не весь набор данных. Возвращаемый результат (итератор или список объектов) передается обратно на слой представления для рендеринга дашборда.
