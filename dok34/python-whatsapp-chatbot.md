# Анализ репозитория python-whatsapp-chatbot

## 1. Техническая реализация и архитектура
Это монолитное легковесное веб-приложение, написанное на Python с использованием фреймворка Flask (судя по структуре с `index.py`).
- Архитектура скриптовая: вся основная логика (маршрутизация HTTP, обработка команд, взаимодействие с API) сосредоточена в `index.py`.
- Бот использует облачный API шлюз `Whapi.Cloud` для взаимодействия с сетью WhatsApp.
- Дополнительно интегрирован клиент OpenAI (через HTTP или библиотеку `openai`) для обеспечения AI-функциональности.

## 2. Функции и как логически это работает
Бот отвечает на входящие сообщения пользователей в WhatsApp и выполняет команды (например, `/AI`).
- Flask сервер (`index.py`) поднимает HTTP-эндпоинт (webhook), на который Whapi.Cloud отправляет POST-запросы при получении новых сообщений в WhatsApp.
- Роутер Flask принимает JSON, извлекает текст сообщения и номер отправителя.
- Встроенный парсер проверяет текст на наличие команд. Если текст начинается с `/AI`, бот берет оставшуюся часть строки и отправляет запрос в OpenAI (ChatGPT API).
- После получения ответа от OpenAI, скрипт вызывает REST API Whapi.Cloud для отправки ответа обратно в WhatsApp чат.

## 3. Как происходит обмен информации, память, потоки данных и так далее
- **Потоки данных:** Пользователь (WhatsApp) -> Whapi.Cloud -> HTTP Webhook (POST JSON) -> Flask сервер -> Анализ текста -> HTTP POST -> OpenAI API -> Получение ответа (JSON) -> HTTP POST -> Whapi.Cloud -> Пользователь.
- **Обмен информацией:** Приложение действует как промежуточный слой (middleware), переводя форматы данных между Whapi (сообщения, номера телефонов, вложения) и OpenAI (массив словарей с ролями user/assistant).
- **Память и состояние:** Приложение по большей части stateless, однако для поддержания контекста диалога (history) с OpenAI оно может сохранять последние сообщения в глобальном словаре (memory dict) с привязкой к номеру телефона или ID чата, либо записывать их в текстовые файлы/БД, если это реализовано в `index.py` (часто кэшируют в оперативной памяти).
