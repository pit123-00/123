# Анализ репозитория YTScribe

## 1. Техническая реализация и архитектура
Проект представляет собой утилиту командной строки (CLI) на языке Python. В архитектуре четко прослеживается модульный подход:
- `cli.py` выступает в качестве точки входа, обрабатывая аргументы через библиотеку `argparse`.
- Основная логика разделена на независимые компоненты: `downloader.py` для скачивания, `extractor.py` для извлечения информации о видео.
- Хранение метаданных и конфигурации абстрагировано через модули `models.py` и `config.py`. Управление состоянием выполняется с помощью `csv_handler.py`.
- Код написан с использованием современных стандартов Python (типизация `from __future__ import annotations`, `typing`).

## 2. Функции и как логически это работает
Программа предназначена для загрузки транскриптов (субтитров) с YouTube и управления архивами каналов.
- Пользователь вызывает команду через CLI (например, скачивание для канала или конкретного видео).
- `cli.py` парсит ввод и вызывает `TranscriptDownloader` (из `downloader.py`), который под капотом использует библиотеку `youtube_transcript_api`.
- Если запрашивается канал, `extractor.py` собирает все ID видео, затем батч-обработчик (`batch.py`) итерируется по ним и ставит в очередь на загрузку.
- Статус каждой загрузки (успех/ошибка) записывается в CSV-файл для возможности возобновления работы при прерывании (`csv_handler.py`).

## 3. Как происходит обмен информации, память, потоки данных и так далее
- **Поток данных:** CLI-аргументы -> Валидация -> YouTube API (сетевой запрос) -> Получение JSON/Text с транскриптом -> Сохранение в файловую систему в формате Markdown с YAML frontmatter.
- **Обмен информацией:** Модули обмениваются типизированными объектами данных (Pydantic или dataclasses из `models.py`), такими как `TranscriptMetadata` и `VideoMetadata`.
- **Память и состояние:** Приложение работает без долгоживущей базы данных. Локальное состояние (история загрузок) поддерживается в CSV-файлах на диске, что минимизирует потребление оперативной памяти (данные обрабатываются потоково по одному видео).
