Отчет-анализ репозитория: youtube-transcript-api

1. Техническая реализация и архитектура:
Легковесная библиотека без зависимостей (только стандартная библиотека requests/httpx обычно заменяется или используется базовая). Реализована как набор функций и классов на Python (TranscriptListFetcher, TranscriptFetcher).

2. Функции и как логически это работает:
Позволяет получить транскрипты/субтитры к видео на YouTube. Логика основана на эмуляции запроса клиента YouTube: скачивание исходного HTML страницы видео, поиск JSON-структуры с параметрами (ytInitialPlayerResponse), извлечение URL транскрипта и скачивание XML с текстом. Поддерживает перевод субтитров через встроенный механизм YT.

3. Как происходит обмен информации, память, потоки данных:
Данные идут от клиента к YouTube (HTTP GET видео). Сервер отдает HTML. Регулярные выражения или JSON-парсер извлекают ключи. Затем делается запрос к серверу транскриптов. Возвращенный XML парсится, извлекая текст, начало (`start`) и длительность (`duration`). Данные объединяются в список словарей Python и возвращаются.
