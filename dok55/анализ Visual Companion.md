# Анализ Superpowers Visual Companion: Визуальное измерение ИИ-разработки

## Введение
Visual Companion (Визуальный помощник) — это одна из самых инновационных функций в проекте Superpowers. Она решает фундаментальную проблему общения с ИИ: сложность обсуждения визуальных концепций, интерфейсов и архитектурных схем через чисто текстовый терминал.

---

## 1. Техническая архитектура и запуск
Visual Companion представляет собой локальный веб-сервер, который агент запускает в фоновом режиме в процессе фазы мозгового штурма.

**Механика работы:**
- **Сервер:** Легковесный Node.js сервер (`server.cjs`), который отдает статический контент.
- **Инфраструктура:** Скрипты `start-server.sh` и `stop-server.sh` управляют жизненным циклом процесса.
- **Персистентность:** При использовании флага `--project-dir` все макеты сохраняются в папку `.superpowers/brainstorm/` внутри проекта. Это позволяет истории дизайна пережить перезапуск сервера.

## 2. Интеграция в рабочий процесс (The Visual Loop)
Visual Companion — это не просто статичная картинка, а интерактивная среда обратной связи.

**Цикл взаимодействия:**
1.  **Запрос:** Агент понимает, что вопрос визуальный (например, "Какой макет главной страницы лучше?").
2.  **Генерация:** Агент пишет HTML-фрагмент в специальную директорию.
3.  **Отображение:** Пользователь открывает локальную ссылку и видит варианты (A, B, C).
4.  **Взаимодействие:** Пользователь кликает на понравившийся вариант в браузере.
5.  **Обратная связь:** Сервер записывает событие (клик) в файл `events`. Агент читает этот файл на следующем ходу и понимает выбор пользователя.

## 3. Модульность и шаблоны (Frame & Fragments)
Система спроектирована крайне эффективно с точки зрения контекстного окна:
- **Frame Template:** Существует базовый шаблон (`frame-template.html`), который содержит все стили (CSS), скрипты для интерактивности и общую структуру.
- **Fragments:** ИИ-агент пишет только "чистый контент" (фрагменты HTML). Ему не нужно каждый раз генерировать стили или обвязку страницы. Это экономит токены и ускоряет работу.

**Доступные визуальные компоненты:**
- **Options:** Карточки для выбора вариантов (A/B/C) с поддержкой мульти-выбора.
- **Split View:** Сравнение "было / стало" или двух разных подходов бок-о-бок.
- **Mockups:** Контейнеры для имитации интерфейсов (Nav-bar, Sidebar, Content).
- **Pros/Cons:** Таблицы преимуществ и недостатков, визуально выделенные цветом.

## 4. Сценарии использования: Когда применять?
Инструкция `visual-companion.md` строго регламентирует использование инструмента, чтобы избежать лишних затрат токенов:

*   **ДА (Visual):** Схемы архитектуры, макеты интерфейсов, сравнение стилей оформления, выбор между сложными логическими схемами.
*   **НЕТ (Textual):** Текстовые требования, списки задач, концептуальные вопросы ("Что вы понимаете под масштабируемостью?").

## 5. Значение для индустрии
Visual Companion превращает ИИ-агента из "кодинг-бота" в "дизайнера-партнера". Это позволяет:
1.  **Уменьшить число итераций:** Визуальный выбор быстрее и точнее текстового описания.
2.  **Повысить доверие:** Пользователь видит "мысли" агента в виде конкретных схем.
3.  **Документировать дизайн:** Все выбранные макеты сохраняются в проекте, создавая визуальный архив принятых решений.

## Заключение
Visual Companion в Superpowers — это пример того, как можно расширить возможности текстовых моделей (LLM), предоставив им "визуальный канал" связи. Это мост между абстрактным кодом и конечным пользовательским интерфейсом, который делает процесс проектирования по-настоящему совместным.
