# Технический анализ ключевых компонентов AI Factory

## Введение
AI Factory (AIF) — это расширяемая платформа для ИИ-разработки, построенная на принципах доказательности, автоматизации и непрерывного обучения. Данный отчет подробно описывает техническую реализацию четырех критических компонентов системы: Skill Evolution, Grounded & Explore, Roadmap и Reflex Loop.

---

## 1. Skill Evolution и механизм aif-evolve
Это механизм "памяти" проекта, позволяющий ИИ учиться на собственных ошибках.

**Технический стек:**
- **Параллельные артефакты:** `patches/` (хранилище опыта) и `skill-context/` (хранилище правил).
- **Механизм патчей:** После каждого исправления через `aif-fix` агент создает патч-файл. Он содержит:
    - Описание бага и Root Cause.
    - Теги (например, #null-check, #async-error).
    - Конкретные "Prevention Points" (точки предотвращения).

**Процесс эволюции:**
1.  **Сбор разведданных:** `aif-evolve` считывает новые патчи, используя `patch-cursor.json` для инкрементальной обработки.
2.  **Анализ пробелов:** Система сравниваетPrevention Points из патчей с текущими инструкциями навыков.
3.  **Генерация Skill-Context:** Если найдена повторяющаяся ошибка, для которой нет правила, создается новое правило в `.ai-factory/skill-context/<skill-name>/SKILL.md`.
4.  **Приоритетность:** Правила из `skill-context` имеют безусловный приоритет над базовыми правилами навыка. Это позволяет адаптировать стандартные навыки под специфику проекта (например, "В этом проекте всегда используйте Prisma-транзакции для записи в БД").

## 2. aif-explore и aif-grounded: Надежность через улики
Эти навыки образуют "защитный слой" системы, предотвращая действия на основе предположений.

**aif-explore (Разведка):**
- Использует субагентов типа `Explore` для параллельного сканирования кодовой базы.
- **Техника:** Агент строит ментальную карту, анализирует зависимости и рисует ASCII-диаграммы структуры.
- **Цель:** Получить достаточно контекста для принятия обоснованных решений.

**aif-grounded (Заземление):**
- **Confidence Gate:** Агент обязан оценить свою уверенность в ответе по шкале от 0 до 100.
- **Условие 100/100:** Ответ дается только если КАЖДОЕ утверждение подтверждено уликой (файлом, логом, результатом команды).
- **Insufficient Information:** Если уверенность < 100, агент выдает не ответ, а "Checklist" того, что нужно сделать пользователю или агенту, чтобы достичь 100% уверенности.

## 3. aif-roadmap: Стратегическое планирование
Навык связывает микро-задачи с макро-целями продукта.

**Механика:**
- **Файл ROADMAP.md:** Центральный артефакт, содержащий вехи (Milestones) и их статусы.
- **Связывание (Linkage):** При создании плана через `aif-plan`, агент предлагает привязать его к конкретной вехе из роадмапа.
- **Верификация:** Навык `aif-verify` проверяет не только тесты, но и "закрытие" пунктов роадмапа, предотвращая "забытые" функции.
- **Rationale:** Для каждого изменения фиксируется обоснование, почему это продвигает проект к цели вехи.

## 4. Reflex Loop: Цикл самокритики
Этот паттерн реализован в навыке `aif-loop` и используется для повышения качества сложного кода.

**Фазы цикла:**
1.  **Generate:** Создание первого варианта реализации.
2.  **Evaluate:** Формальная проверка (тесты, линтеры).
3.  **Critique:** Агент (или субагент) выступает в роли жесткого ревьюера, ища логические ошибки, проблемы производительности и безопасности.
4.  **Refine:** Исправление кода на основе собственной критики.

**Техническая ценность:** Этот подход позволяет обойти ограничение "одного прохода" LLM, когда модель склонна соглашаться со своим первым (иногда ошибочным) решением.

---

## 5. Взаимосвязь компонентов
Система работает как единый механизм:
- `aif-explore` дает контекст.
- `aif-roadmap` дает направление.
- `aif-plan` создает структуру.
- `aif-loop` обеспечивает качество исполнения.
- `aif-fix` + `aif-evolve` замыкают цикл, предотвращая повторение ошибок в будущем.

## Заключение
AI Factory — это пример перехода от простых шаблонов промптов к сложным когнитивным архитектурам. Техническая реализация через инкрементальные патчи, эволюцию контекста и доказательное заземление делает эту систему одной из самых надежных сред для автономной ИИ-разработки.
