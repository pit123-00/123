# Анализ FlashRAG (RUC-NLPIR/FlashRAG)

## 23 современных алгоритма RAG и объединение извлечения с рассуждением
FlashRAG — это модульный тулкит для систем генерации, дополненной поиском (Retrieval Augmented Generation).
- В репозитории реализовано 23 различных алгоритма RAG. Платформа унифицирует их, предоставляя общие интерфейсы для Retrievers (модули извлечения информации) и Generators (модули генерации ответа).
- Недавно было добавлено **7 методов, основанных на рассуждениях (reasoning-based retrieval)**. Они комбинируют возможности рассуждений LLM с внешним поиском, что значительно улучшает производительность в задачах многошагового вывода (multi-hop reasoning).
- В `flashrag/pipeline/reasoning_pipeline.py` реализован класс `ReasoningPipeline`. Эта архитектура позволяет агенту (Assistant) сначала обдумывать логику решения, используя токены `<think> ... </think>`, в процессе которого агент может осуществлять промежуточные поиски для неясной информации (`<|begin_of_query|> ... <|end_of_query|>`). Затем система подставляет релевантные документы, а агент формирует финальный ответ (`<answer> ... </answer>`). Эта методика поддерживает алгоритмы типа Search-R1, O2-Searcher и другие.
