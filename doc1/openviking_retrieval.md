# Технический анализ OpenViking: Механизм иерархического поиска (Retrieval Mechanism)

В OpenViking классический RAG заменен двухступенчатой системой извлечения: Анализ намерений (Intent Analysis) + Иерархический рекурсивный поиск (Hierarchical Retrieval) с использованием Rerank.

## Класс `HierarchicalRetriever`
Ядром системы поиска является класс `HierarchicalRetriever`, описанный в `openviking/retrieve/hierarchical_retriever.py`. Этот класс осуществляет поиск по структуре каталогов, используя очередь с приоритетом (Priority Queue).

Алгоритм разбит на несколько этапов:
1. **Определение корневых директорий (Root Mapping):** На основе типа контекста (`MEMORY`, `RESOURCE`, `SKILL`) система понимает, с каких виртуальных папок (URI) нужно начать поиск (например, `viking://resources`).
2. **Глобальный векторный поиск (Global Vector Search):** Производится поиск по векторной БД для нахождения лучших "отправных точек" (`STARTING_POINTS`). Это сужает зону поиска до нескольких папок.
3. **Объединение и переранжирование:** Найденные точки сливаются, и к их `.overview.md` применяется стратегия `Rerank`. В режиме `THINKING` используется внешняя LLM (например, `doubao-seed-rerank`) для выставления точных оценок релевантности. Если Rerank падает, система откатывается на векторные оценки (`Vector scores`).

### Рекурсивный поиск (Recursive Search Algorithm)
Вместо того чтобы выдавать плоский список файлов, `HierarchicalRetriever` обходит файловую систему вглубь:
- Поддерживается очередь директорий `dir_queue` с приоритизацией на базе оценок.
- Для каждой папки в очереди запрашиваются её дети (`children`).
- **Распространение оценок (Score Propagation):** Оценка дочернего элемента вычисляется по формуле взвешенной суммы: `final_score = 0.5 * embedding_score + 0.5 * parent_score` (параметр `SCORE_PROPAGATION_ALPHA = 0.5`). Это гарантирует, что если родительская директория крайне релевантна, ее дети получат бонус к поиску.
- Если дочерний элемент является директорией и проходит порог, он добавляется обратно в `dir_queue`.
- **Детекция сходимости (Convergence Detection):** Чтобы избежать бесконечного обхода огромных файловых деревьев, цикл проверяет: если `Top-K` результатов не изменяется на протяжении 3 итераций (`MAX_CONVERGENCE_ROUNDS = 3`), рекурсия досрочно прерывается.

Результатом является список `MatchedContext`, содержащий иерархически связанные элементы контекста.
