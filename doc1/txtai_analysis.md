# Анализ txtai (neuml/txtai)

## Объединение векторных индексов, графовых сетей и реляционных SQL баз данных
Ключевое преимущество `txtai` заключается в предоставлении единого API (`Embeddings`), которое объединяет различные виды поиска.
Как видно в `src/python/txtai/embeddings/base.py`:
- `self.indexes` обрабатывает векторные индексы, где документы преобразуются в векторные представления (эмбеддинги).
- `self.database` позволяет выполнять SQL-поиск (базирующийся на SQLite, DuckDB, и других реляционных СУБД) по документам. SQL-парсинг и интеграция реализованы в `src/python/txtai/database/sql/base.py`. Это позволяет комбинировать полнотекстовый поиск, WHERE-фильтрацию и семантический поиск.
- `self.graph` обеспечивает поддержку графовых нейронных сетей и связей между документами. Использование метода `batchsearch` и графовых фабрик (`creategraph`) позволяет возвращать подграфы (subgraphs) как результаты поиска наряду с плоскими результатами.

## Мультимодальное индексирование
`txtai` поддерживает мультимодальность «из коробки», обеспечивая работу с текстом, аудио, видео и изображениями.
- Энкодеры для различных медиа-файлов расположены в `src/python/txtai/database/encoder/` (например, `image.py`, который сжимает изображения в бинарный формат для сохранения в БД).
- Процесс (pipeline) эмбеддингов поддерживает загрузку предобученных моделей с Hugging Face, способных преобразовывать не только текстовые запросы, но и изображения (CLIP), аудио и другие типы медиа в векторное пространство, позволяя выполнять поиск по изображениям с помощью текстовых запросов или находить изображения по изображениям.
