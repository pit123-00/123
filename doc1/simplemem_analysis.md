# Анализ SimpleMem (aiming-lab/SimpleMem)

## Structured Indexing (Многопроекционное индексирование)
В SimpleMem память индексируется не просто как сырой текст, а с использованием нескольких "проекций" (multi-projection) для обеспечения более надежного поиска. Как показано в архитектуре проекта и файле `core/memory_builder.py`:
- Индексация является вторым этапом (Stage 2) пайплайна системы памяти.
- Индексирование происходит в нескольких слоях: семантическом (semantic embeddings), лексическом (lexical, например, BM25) и символическом (symbolic metadata - привязки по времени, авторам и другим сущностям).
- Процесс компрессии диалогов (Semantic Structured Compression) создает компактные юниты памяти с разрешенными кореференциями и абсолютными временными метками, которые затем сохраняются с использованием векторной базы данных LanceDB (`database/vector_store.py`).

## Adaptive Retrieval (Адаптивный поиск)
SimpleMem не использует фиксированную глубину поиска. Механизм `HybridRetriever` (Stage 3), реализованный в `core/hybrid_retriever.py`, адаптируется под запрос пользователя:
- Сначала оценивается сложность запроса (query complexity, $C_q$).
- Глубина извлечения (retrieval depth) динамически модулируется по формуле: $k_{dyn} = \lfloor k_{base} \cdot (1 + \delta \cdot C_q) \rfloor$.
- Извлечение данных происходит параллельно по всем многопроекционным слоям (семантическому, лексическому, символическому), после чего результаты объединяются ($R_{sem} \cup R_{lex} \cup R_{sym}$), предоставляя наиболее точный контекст для генерации ответа.
