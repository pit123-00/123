# Технический анализ FlashRAG: ReasoningPipeline

## Принцип работы методов, основанных на рассуждениях
FlashRAG добавил поддержку reasoning-based retrieval, интегрировав 7 современных алгоритмов (Search-R1, O2-Searcher, R1-Searcher и др.). Эти методы решают проблему "вслепую" генерируемых поисковых запросов в сложных многошаговых задачах (multi-hop reasoning).

## Класс `ReasoningPipeline`
В файле `flashrag/pipeline/reasoning_pipeline.py` реализован пайплайн, в котором:
1. **Промптинг с инструкциями:** Системный промпт инструктирует агента выдавать мыслительный процесс внутри тегов `<think> ... </think>` и финальный ответ внутри `<answer> ... </answer>`.
2. **Динамический поиск (Interleaved Retrieval):** Агенту разрешено прерывать свои размышления, генерируя специальные токены запроса: `<|begin_of_query|> query <|end_of_query|>`.
3. **Парсинг и извлечение:** Метод пайплайна парсит вывод LLM в реальном времени. Когда он встречает `begin_of_query`, он извлекает текст запроса (с помощью регулярных выражений или функций `extract_between`).
4. **Интеграция с Retriever:** Полученный запрос отправляется в компонент `Retriever`, который возвращает релевантные документы из векторного или поискового индекса.
5. **Вставка контекста:** Пайплайн возвращает агенту результаты поиска, обернутые в теги `<|begin_of_documents|> ... <|end_of_documents|>`. Агент продолжает генерацию (внутри тега `<think>`), учитывая полученную информацию, пока не будет готов выдать финальный `<answer>`.

Это обеспечивает итеративный цикл рассуждений с поиском, значительно повышая точность и достоверность результатов в сложных логических цепочках.
