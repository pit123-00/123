# Анализ репозитория: feed2json

## 1. Техническая реализация и архитектура
Проект `feed2json` — это утилитарный Python-модуль, состоящий всего из одного файла (`feed2json.py`). Его архитектура максимально примитивна: это скрипт-конвертер (adapter pattern), который выступает прослойкой между двумя форматами.
В основе работы лежит внешняя библиотека `feedparser`. Скрипт принимает на вход XML фид (RSS или Atom), парсит его с помощью `feedparser`, а затем явно маппит (перекладывает) полученный Python-словарь в новую структуру, соответствующую спецификации JSON Feed 1.1.

## 2. Функции и как логически это работает
Главная и единственная функция в модуле — `feed2json()`.
- **Входные данные:** Функция принимает либо URL фида (`feed_url`), либо путь к локальному XML файлу (`feed_file_path`), либо сырую XML-строку (`feed_string`).
- **Парсинг:** Вызывается `feedparser.parse(feed_arg)`, который превращает XML-структуру в удобный объект-словарь.
- **Маппинг (Трансформация):**
  Создается базовый словарь `json_feed` с обязательными ключами (version, title, feed_url). Для извлечения данных написана вспомогательная функция `gfnn` (get first non none), которая пытается найти нужные данные в словаре `feedparser` под разными возможными ключами (например, `title` или `subtitle`, `link` или `id`).
  Затем скрипт в цикле проходит по массиву `feed.entries` (статьи фида) и для каждой записи создает словарь `item`.
- **Обработка дат и контента:** Время, полученное из `feedparser` (`published_parsed`, `updated_parsed`), конвертируется в формат RFC 3339 с помощью функции `struct_time_to_rfc3339`. Контент перебирается: `text/plain` уходит в `content_text`, а HTML — в `content_html`. Медиа-вложения (enclosures) маппятся в массив `attachments`.
- **Выходные данные:** Возвращается готовый Python-словарь, который можно легко сериализовать в JSON.

## 3. Как происходит обмен информации память потоки данных
- **Память и состояние:** Скрипт не хранит состояния. Он загружает исходный XML в оперативную память (через `feedparser`), выделяет память под новый словарь и возвращает его. После завершения функции вся память освобождается сборщиком мусора.
- **Потоки данных:**
  - Вход (URL/Строка/Файл) -> `feedparser` (Синтаксический анализ XML) -> Объект `feed_info` (Словарь).
  - Скрипт статично и жестко перекладывает ключи из объекта `feed_info` в новую структуру `json_feed`.
  - Поток однонаправленный, никаких сетевых запросов кроме тех, что скрыты внутри вызова `feedparser.parse()`, скрипт не выполняет. Он служит исключительно как процессор трансформации данных.
