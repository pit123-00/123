# SONA: Самообучение на каждом запросе

**SONA** (Self-Optimizing Neural Architecture), реализованная в крейте `sona`, является интеллектуальным центром управления RuVector. Она реализует концепцию непрерывного обучения (Lifelong Learning), позволяя ИИ-системе совершенствоваться непосредственно в процессе эксплуатации, обучаясь на каждом взаимодействии с пользователем.

## 1. Архитектура адаптивного цикла
SONA координирует три независимых по времени и глубине петли обучения через компонент `LoopCoordinator`:
1.  **Instant Loop**: Мгновенная адаптация (менее 100 мкс), использующая MicroLoRA.
2.  **Background Loop**: Фоновая консолидация (ежечасно), обновляющая веса на основе накопленных траекторий.
3.  **Deep Loop**: Периодическое полное переобучение с использованием EWC++ для защиты фундаментальных знаний.

## 2. Реализация функций обучения SONA

### 31. `SonaEngine::begin_trajectory(query_embedding) -> TrajectoryBuilder`
Инициализация записи сеанса обучения.
- **Логика**: Генерирует уникальный идентификатор сессии и фиксирует начальное состояние системы (вектор запроса).
- **Важность**: Траектория позволяет восстановить контекст, в котором было принято решение, что необходимо для Reinforcement Learning.

### 32. `MicroLoRA::forward(input, output)`
Применение сверхбыстрой адаптации весов.
- **Логика**: Выполняет низкоранговое преобразование $Y = X + \alpha(X \cdot A) \cdot B$, где $A$ и $B$ — матрицы ранга 1 или 2.
- **Оптимизация**: Код в `lora.rs` содержит ручные SIMD AVX2-инструкции для параллельной обработки элементов вектора, что сводит задержку к минимуму.

### 33. `MicroLoRA::accumulate_gradient(signal)`
Обновление весов "на лету".
- **Логика**: На основе сигнала обратной связи (reward) вычисляет примерное направление коррекции весов.
- **Особенности**: Не требует классического Backpropagation, что позволяет обучать модель прямо на CPU без использования GPU.

### 34. `EwcState::consolidate(current_weights)`
Защита от забывания (Elastic Weight Consolidation).
- **Логика**: Вычисляет важность каждого параметра модели через информационную матрицу Фишера.
- **Механизм**: При последующем обучении система накладывает штраф за изменение наиболее важных для "старой" памяти весов.

### 35. `ReasoningBank::find_similar(query_embedding, k)`
Механизм ассоциативного обучения.
- **Логика**: Кластеризует успешные паттерны поведения. При получении нового запроса система ищет в банке аналогичные ситуации из прошлого.
- **Эффект**: Если похожий запрос уже решался успешно, SONA мгновенно подгружает соответствующие веса адаптера.

## 3. Философия "Живой Памяти"
Традиционные векторные БД возвращают одни и те же результаты на один и тот же запрос вечно. RuVector с SONA обучается: если пользователь раз за разом выбирает третий результат в выдаче вместо первого, SONA через GNN и MicroLoRA скорректирует веса так, что в следующий раз релевантный результат окажется на первом месте. Это делает RuVector не просто хранилищем, а когнитивным партнером пользователя.
