# Глубокий технический анализ 5: Адаптивные рабочие процессы и Life Engine (Confidence Gating & Nudging)

## 1. Life Engine: От пассивного хранилища к активному помощнику

В отличие от большинства систем управления знаниями (PKM), которые пассивно ждут запроса пользователя, рецепт `Life Engine` в OB1 реализует модель "проактивного" ИИ-агента.

### 1.1. Архитектура проактивности
Life Engine — это надстройка, которая регулярно анализирует базу знаний, календарь и внешние данные пользователя.
- **Пуш-модель (Push-based Interaction)**: Система сама инициирует взаимодействие через Telegram или Discord.
- **Интеграция с контекстом**: Она связывает данные из Open Brain (прошлые мысли, идеи) с текущими событиями (календарь, задачи). Например, перед встречей с человеком система может отправить "проактивный брифинг" с напоминанием о темах, обсуждавшихся в прошлый раз.
- **Мультисистемный охват**: Life Engine подключается к данным о здоровье, привычках и финансах, создавая единый "когнитивный дашборд" дня.

### 1.2. Визуализация: Life Engine Video
Инновационным техническим решением является автоматическая генерация видео-брифингов. Система преобразует текстовую выжимку в сценарий, озвучивает его и рендерит короткое видео, превращая персональную память в "персональное информационное агентство".

## 2. Адаптивный шлюз захвата (Adaptive Capture Gating)

Для поддержания высочайшей чистоты данных (Data Hygiene) в OB1 реализован механизм контроля на входе, основанный на уверенности модели.

### 2.1. Алгоритм шлюзования (Confidence Logic)
При каждом захвате мысли экстрактор выдает показатель уверенности (`confidence`) от 0 до 10. Система сравнивает его с порогом (`threshold`), хранящимся в таблице `capture_thresholds`.
- **Автоматическое прохождение**: Если `confidence >= threshold`, данные сразу записываются в базу.
- **Ручной шлюз (Manual Gate)**: Если уверенность ниже порога, система приостанавливает процесс и создает запись в `classification_outcomes` со статусом `pending`, запрашивая подтверждение у пользователя.

### 2.2. Алгоритм обучения через "подталкивание" (Threshold Nudging)
Система динамически адаптируется к стандартам пользователя — это форма локального обучения без переобучения всей модели.
- **Сценарий "Принято" (Success)**: Если пользователь подтверждает автоматическое решение системы, порог для этого типа данных немного **снижается** (`threshold -= 0.02`). Система становится более "смелой".
- **Сценарий "Исправлено" (Correction)**: Если пользователь исправляет классификацию (например, меняет "задачу" на "идею"), порог для этой категории **повышается** (`threshold += 0.02`). Система становится более "осторожной" и в следующий раз при аналогичной уверенности спросит совета.

## 3. Обработка неопределенности и консенсус

Для обеспечения точности в критических доменах (здоровье, финансы) система использует механизм "консенсуса":
- Она может запустить классификацию дважды через разные модели (например, Sonnet и Haiku).
- Если модели расходятся в определении типа данных, итоговый показатель `confidence` получает штрафной коэффициент (`CONSISTENCY_FACTOR`, обычно 0.6). Это практически гарантирует, что спорная запись попадет на проверку человеку.

## 4. Техническая реализация в PostgreSQL

Хранение и обновление порогов реализовано через специализированную таблицу:
```sql
CREATE TABLE capture_thresholds (
    item_type TEXT PRIMARY KEY, -- тип (idea, task, etc.)
    threshold NUMERIC DEFAULT 0.75,
    sample_count INTEGER DEFAULT 0,
    updated_at TIMESTAMPTZ
);
```
Использование типа `NUMERIC` позволяет производить точные манипуляции с порогами на уровне сотых долей, а `sample_count` помогает системе понимать "стаж" обучения для каждой конкретной категории знаний.

## Заключение
Адаптивные процессы превращают OB1 из статичного архива в динамическую систему, которая подстраивается под стандарты своего владельца. **Life Engine** обеспечивает проактивное использование накопленного опыта, а **Adaptive Gating** гарантирует, что этот опыт будет точным и правильно классифицированным, создавая самосовершенствующийся фундамент для персонального интеллекта.
