# Технический анализ: Алгоритм многофазного извлечения (Panning for Gold)

## 1. Введение
В системе OB1 (Open Brain) обработка "шумных" сырых данных, таких как многочасовые транскрипты встреч или хаотичные потоки сознания, реализуется через продвинутый навык `Panning for Gold` ("Просеивание золота"). В отличие от традиционных ИИ-суммаризаторов, которые выполняют один проход по тексту, Panning использует многофазную архитектуру извлечения. Данный документ анализирует техническую реализацию этого процесса.

## 2. Проблема линейного извлечения
Стандартные LLM-агенты часто пропускают важные детали при обработке длинных документов из-за:
- **Потери в середине (Lost in the Middle)**: Модели хуже помнят информацию из центра контекстного окна.
- **Галлюцинаций сжатия**: Пытаясь обобщить, модель может "выбросить" мелкую, но критически важную идею (например, упомянутый контакт или странную гипотезу).

## 3. Многофазная архитектура Panning
Алгоритм разбит на три четких технических этапа: **Inventory** (Инвентаризация), **Evaluation** (Оценка) и **Synthesis** (Синтез).

### 3.1. Фаза 1: Инвентаризация "без фильтров"
Главный технический принцип этой фазы — запрет на отбрасывание информации.
- **Двухпроходное чтение**: Сначала агент читает краткое содержание (если есть), чтобы наметить основные вехи. Затем он выполняет полный скан текста.
- **Захват цитат**: Для каждой выделенной нити (thread) агент обязан найти и сохранить точную цитату из первоисточника. Это исключает галлюцинации и позволяет пользователю верифицировать находку.
- **Сохранение в файл**: Результат фазы 1 немедленно записывается в постоянный файл `YYYY-MM-DD-inventory.md`. Это гарантирует, что данные не будут потеряны при переполнении памяти ИИ-агента.

### 3.2. Фаза 2: Параллельная оценка (Deep Brainstorming)
После того как список идей ("самородков") сформирован, система переходит к их анализу.
- **Триаж**: Идеи делятся на категории `ACT NOW` (срочные), `RESEARCH MORE` (перспективные) и `PARK` (в архив).
- **Фоновые агенты**: Для каждой идеи категории `ACT NOW` система может запустить независимого агента (часто на более мощной модели, например Claude 3.5 Opus). Он проводит глубокое исследование: проверяет техническую реализуемость, ищет аналоги в GitHub и связи в существующей базе Open Brain.

### 3.3. Фаза 3: Синтез и автоматический захват
Финальный этап собирает результаты всех оценок в единый документ `gold-found.md`.
- **Автоматический `capture_thought`**: Каждая утвержденная идея (`ACT NOW`) автоматически отправляется в базу данных Open Brain через MCP-инструмент.
- **Формирование COS (Current Operating State)**: Система обновляет списки текущих задач и решений пользователя, основываясь на результатах "просеивания".

## 4. Технические инновации
- **Grep-ориентированный поиск**: Вместо того чтобы перечитывать весь документ для уточнения детали, агент использует команду `grep` по ключевым словам из инвентаря. Это экономит до 80% токенов.
- **Устойчивость к сбоям**: Запись результатов каждой фазы на диск решает проблему прерывистости длинных сессий. Даже если агент "забудет" контекст, он прочитает файлы и продолжит работу.

## 5. Заключение
Алгоритм Panning for Gold превращает ИИ из пассивного слушателя в активного аналитика данных. Технический переход от **линейного чтения** к **многофазному инвентарному анализу** в сочетании с **параллельной оценкой** позволяет OB1 извлекать максимум ценности из любого объема информации, гарантируя, что ни одна важная мысль пользователя не будет потеряна в "шуме" обсуждения.
