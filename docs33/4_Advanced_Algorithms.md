# Технический отчет 4: Продвинутые агентные алгоритмы и адаптивность

## 1. Введение: Интеллект за пределами хранения
Система OB1 (Open Brain) выделяется на фоне конкурентов наличием специфических алгоритмов, которые позволяют системе обучаться, извлекать глубокие смыслы из шума и самостоятельно наращивать возможности. Данный отчет анализирует три столпа агентной логики: Адаптивное шлюзование, Просеивание данных и Рекурсивное создание навыков.

## 2. Адаптивный шлюз захвата (Confidence Gating)
Этот механизм (рецепт `adaptive-capture-classification`) решает проблему качества данных на входе. Он реализует логику "Доверяй, но проверяй".

### 2.1. Алгоритм уверенности
При классификации каждой мысли LLM выдает оценку `confidence` (0-10).
- **Auto-Accept**: Если оценка выше порога, запись проходит автоматически.
- **Manual Review**: Если уверенность низкая, система создает запрос на подтверждение пользователем.

### 2.2. Обучение через "Подталкивание" (Nudging)
Система динамически корректирует пороги `threshold` в ответ на действия пользователя.
- Если пользователь часто исправляет авто-захваченные задачи, порог для категории `task` повышается, делая систему более осторожной.
- Если подтверждает — порог снижается, повышая автономность.
Это форма локального машинного обучения, которое подстраивает систему под персональные стандарты качества конкретного человека.

## 3. Алгоритм "Просеивание золота" (Panning for Gold)
Навык `panning-for-gold.skill.md` предназначен для обработки экстремально шумных данных (транскрипты, потоки сознания).

### 3.1. Фаза 0.5: Дефрагментация спикеров
Техническая реализация включает "Speaker Audit". Система ищет в транскрипте уникальные фразы пользователя (упоминание его специфических проектов, семьи), которые служат "семантическими якорями". На основе этих якорей система исправляет ошибки автоматической атрибуции речи, гарантируя, что мысли будут приписаны верному человеку.

### 3.2. Многофазное извлечение потоков (Threads)
Вместо одного прохода по тексту агент выполняет цикл:
1. **Inventory**: Создание полного списка всех затронутых тем с точными цитатами.
2. **Deep Evaluation**: Запуск независимых ИИ-агентов для мозгового штурма по каждой важной идее (проверка осуществимости, поиск связей в базе).
3. **Synthesis**: Сборка выводов в итоговый документ и автоматический захват (`capture_thought`) в память.

## 4. Claudeception (Aiception): Самосовершенствование
Это мета-алгоритм, позволяющий системе расширять свою функциональность без участия человека.

### 4.1. Кодификация опыта (Skills-as-Data)
Когда агент находит нестандартное решение проблемы или обнаруживает "подводные камни" в каком-либо инструменте, он:
1. Анализирует свой лог работы.
2. Формирует новый файл навыка `.skill.md` (Problem -> Context -> Solution).
3. Сохраняет его в базу знаний Open Brain.

### 4.2. Механизм активации
Поскольку навыки индексируются как обычные записи, в будущих сессиях любой новый агент может найти этот навык через семантический поиск и мгновенно "научиться" приемам, которые были разработаны его предшественниками.

## 5. Итог
Продвинутые алгоритмы OB1 превращают "мозг" из пассивного архива в активного участника творческого и рабочего процесса. **Адаптивные пороги** обеспечивают чистоту данных, **Panning for Gold** гарантирует извлечение максимума ценности из шума, а **Claudeception** создает петлю положительной обратной связи, позволяя системе становиться умнее с каждой новой задачей.
